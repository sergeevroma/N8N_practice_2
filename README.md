# Tiny Notes

Tiny Notes — консольный блокнот на Python. Он сохраняет текстовые заметки в локальный
JSON-файл, показывает их список и ищет заметки по подстроке.

Это небольшой учебный проект для проверки обработки GitHub Issues. В текущей версии
намеренно оставлена одна ошибка поиска, описанная ниже.

## Требования и запуск

- Python 3.10 или новее.
- Используется только стандартная библиотека, устанавливать зависимости не нужно.

Откройте терминал в папке проекта:

```bash
python3 notes.py --help
```

Если в вашей системе Python вызывается командой `python`, используйте её вместо
`python3` во всех примерах.

## Команды

### Добавление заметки

```bash
python3 notes.py add "Buy Milk"
```

Для нового хранилища результат:

```text
Добавлена заметка #1.
```

Заметки получают последовательные целочисленные идентификаторы. Пробелы по краям
текста удаляются; пустую заметку добавить нельзя. Русский текст поддерживается.

### Список заметок

```bash
python3 notes.py list
```

Результат после добавления первой заметки:

```text
#1: Buy Milk
```

Для пустого или ещё не созданного хранилища программа выводит `Заметок нет.`.
Список сохраняет порядок добавления заметок.

### Поиск

```bash
python3 notes.py search "Milk"
```

Поиск выбирает заметки, содержащие указанную подстроку. Ожидаемое поведение — поиск
без учёта регистра: `Milk`, `milk` и `MILK` должны находить одну и ту же заметку.
В текущей версии это поведение нарушено: см. раздел об учебной ошибке.

Если совпадений нет, выводится `Совпадений нет.`. Пустая строка поиска не допускается.

## Отдельные хранилища

По умолчанию программа использует `notes.json` в текущей рабочей папке терминала.
Глобальный аргумент `--file` задаёт другой путь и указывается **перед командой**:

```bash
python3 notes.py --file study-notes.json add "Read chapter 2"
python3 notes.py --file study-notes.json list
python3 notes.py --file personal-notes.json add "Buy bread"
python3 notes.py --file personal-notes.json search "bread"
```

Эти два файла независимы: у каждого свой список заметок и свои идентификаторы.
Можно передать и путь с папкой:

```bash
python3 notes.py --file data/study-notes.json add "Prepare for exam"
```

При добавлении первой заметки файл и недостающие родительские папки создаются
автоматически. Команды `list` и `search` не создают файл и не изменяют заметки.

## Формат данных

Хранилище — JSON-массив объектов с целочисленным `id > 0` и строковым `text`:

```json
[
  {
    "id": 1,
    "text": "Buy Milk"
  }
]
```

Файл сохраняется в UTF-8. При некорректном JSON или неверной структуре данных
программа выводит ошибку и не перезаписывает хранилище.

Локальные JSON-файлы исключены из Git через `.gitignore`. Не загружайте личные
заметки в публичный репозиторий.

## Известная учебная ошибка

Поиск учитывает регистр, хотя должен игнорировать его.

Для воспроизведения используйте отдельный файл, который ещё не содержит заметок:

```bash
python3 notes.py --file bug-notes.json add "Buy Milk"
python3 notes.py --file bug-notes.json search "milk"
```

Ожидаемый результат:

```text
#1: Buy Milk
```

Фактический результат:

```text
Совпадений нет.
```

При поиске `Milk` заметка находится. Ошибка намеренно оставлена в `search_notes`,
чтобы по ней можно было создать воспроизводимый bug report.
